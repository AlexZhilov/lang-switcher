# lang-switcher

Исправляет раскладку выделенного текста RU ↔ EN и одновременно меняет язык
ввода. Также переключает регистр текста.

| Горячая клавиша | Действие |
| --- | --- |
| **Ctrl+Shift+Пробел** | `ghbdtn` → `привет` и русский язык ввода; обратное преобразование — аналогично |
| **Ctrl+Shift+Q** | `Привет` → `привет`, `привет` → `ПРИВЕТ` |

Выделите текст в редактируемом поле и нажмите сочетание.

## Требования

**GNOME Shell 43, X11, Python 3.10+.** Установщик рассчитан на системы
с APT/dpkg: Debian, Ubuntu и производные. Пользовательские расширения GNOME
должны быть включены. Wayland и другие основные версии GNOME не поддерживаются.

## Установка

Запустите в Bash-терминале рабочего стола, **без sudo**:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/AlexZhilov/lang-switcher/master/bootstrap.sh)
```

Установщик сам поставит зависимости, сохранит прежние файлы и настроит горячие
клавиши. Пароль sudo запрашивается только для системных пакетов. Временные
скачанные файлы удаляются после установки.

Для загрузки модуля GNOME в английской раскладке нажмите **Alt+F2 → r → Enter**
или выйдите из учётной записи и войдите снова.

Ручная установка из [релиза](https://github.com/AlexZhilov/lang-switcher/releases/latest):

```bash
sha256sum --check lang-switcher.tar.gz.sha256 &&
tar -xzf lang-switcher.tar.gz &&
cd lang-switcher &&
./install.sh
```

Предварительно скачайте архив и файл SHA256 в одну папку.

## Управление

```bash
lang-switcher status      # Состояние программы
lang-switcher update      # Обновление
lang-switcher rollback    # Откат последнего обновления
lang-switcher uninstall   # Удаление с восстановлением прежнего состояния
```

Bash дополняет команды и параметры по **Tab**, а `restore` — пути к копиям.
В новом терминале дополнение подключается автоматически.

Если команда не найдена, используйте `~/.local/bin/lang-switcher`.
Код: `~/.local/lib/lang-switcher/`, данные: `~/.local/share/lang-switcher/`.
Прежняя установка переносится автоматически. Удаление сохраняет резервные
копии и общие системные пакеты.

Работает с выделением. Текстовый буфер восстанавливается; изображения и другие
форматы буфера не сохраняются.
