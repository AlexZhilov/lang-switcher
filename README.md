# lang-switcher

**lang-switcher** исправляет текст, набранный в неверной русской или английской
раскладке, и одновременно выбирает соответствующий язык ввода. После исправления
можно продолжать печатать на нужном языке без отдельного Alt+Shift.

## Возможности

| Горячая клавиша | Действие | Пример |
| --- | --- | --- |
| **Ctrl+Shift+Пробел** | Преобразовать выделенный текст RU ↔ EN и выбрать язык ввода | `ghbdtn` → `привет`, включается русский |
| **Ctrl+Shift+Пробел** | Обратное преобразование | `руддщ` → `hello`, включается английский |
| **Ctrl+Shift+Q** | Переключить регистр всего выделенного текста по первой букве | `Привет` → `привет`, `привет` → `ПРИВЕТ` |

Выделите текст в редактируемом поле и нажмите нужное сочетание.
Без выделения программа ничего не меняет. Для изменения регистра язык ввода
сохраняется. Если после исправления нужный язык уже выбран, он остаётся активным.

Дополнительно:

- поддерживаются многострочный текст, ведущие пробелы и отступы;
- язык меняется напрямую через модуль GNOME, без имитации Alt+Shift;
- повторные вызовы во время обработки игнорируются, чтобы операции не пересекались;
- текстовый буфер обмена восстанавливается после обработки, включая ошибки;
- выделенный текст не выводится в журнал и не отправляется по HTTP.

Требуется выделение: автоматического распознавания ошибочной раскладки во время
печати и исправления последнего слова без выделения нет. Сохранение буфера
рассчитано на текст; картинки и другие форматы не сохраняются.

## Совместимость

Поддерживается **Zorin OS с GNOME Shell 43, сеансом X11 и Python 3.10+**.
Wayland и другие основные версии GNOME пока не поддерживаются.

Проверить окружение можно в терминале:

```bash
gnome-shell --version
echo "$XDG_SESSION_TYPE"
```

Ожидаются версия GNOME `43.x` и значение `x11`. Также должна быть включена
поддержка пользовательских расширений в приложении «Расширения».

## Установка из архива

Этот способ подходит для чистой установки и замены прежнего пользовательского
скрипта. Скопируйте на целевой ПК два файла:

- `lang-switcher.tar.gz`;
- `lang-switcher.tar.gz.sha256`.

Откройте терминал в папке с этими файлами и выполните:

```bash
sha256sum --check lang-switcher.tar.gz.sha256
tar -xzf lang-switcher.tar.gz
cd lang-switcher
./install.sh --check-only
./install.sh
```

Продолжайте распаковку и установку только после успешной проверки SHA256.
`--check-only` проверяет совместимость и конфликты горячих клавиш без установки.

**Запускайте установщик от обычного пользователя, без `sudo ./install.sh`.**
При необходимости он отдельно запросит пароль sudo для установки системных
пакетов `python3-venv`, `xclip`, `libglib2.0-bin`. Python-зависимости установятся
в собственное окружение программы; системный pip не используется.

Если системные пакеты уже установлены, доступна установка без сети:

```bash
./install.sh --offline
```

## Установка одной командой с GitHub

> Пока GitHub-репозиторий и первый Release не опубликованы, URL ниже — шаблон.
> Перед использованием замените `OWNER/lang-switcher` на реальный репозиторий.

Из Bash-терминала рабочего стола:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/OWNER/lang-switcher/main/bootstrap.sh) --repo OWNER/lang-switcher
```

Команда скачает последний Release, проверит контрольную сумму, распакует комплект,
выполнит установку и автоматически удалит временную загрузку. Установленная
программа и резервные копии сохранятся. Для загрузки нужен `curl`.

## Завершение первой установки

Чтобы GNOME загрузил новый модуль:

1. Переключитесь на английскую раскладку.
2. Нажмите **Alt+F2**.
3. Введите **r** и нажмите **Enter**.

Это перезапуск оболочки GNOME в X11. Альтернативный способ — выйти из учётной
записи и войти снова. Установщик сам оболочку не перезапускает и сообщает,
нужен ли перезапуск после конкретной установки или обновления.

Затем проверьте состояние:

```bash
~/.local/bin/lang-switcher status
```

Откройте текстовый редактор, введите `ghbdtn`, выделите слово и нажмите
**Ctrl+Shift+Пробел**. Должно появиться `привет`, а следующая буква должна
вводиться на русском языке.

Если `~/.local/bin` уже входит в PATH, команды можно вызывать просто как
`lang-switcher`, без полного пути.

## Обновление поверх старого скрипта

Удалять прежнюю версию вручную не требуется. Запустите тот же установщик:
он сохранит резервные копии, заменит файлы, обновит известные привязки
`switch_layout.sh` и `switch_case.sh`, обнаружит старый модуль по его интерфейсу
и включит новый. Пути настраиваются для текущего пользователя автоматически.

Чужие горячие клавиши сохраняются. Если нужное сочетание занято другой
программой, установщик сообщит о конфликте; освободите сочетание в настройках
GNOME и повторите установку.

## Управление установленной версией

| Команда | Действие |
| --- | --- |
| `lang-switcher status` | Показать версию и состояние модуля GNOME |
| `lang-switcher update` | Установить последний GitHub Release |
| `lang-switcher rollback` | Вернуть версию и настройки перед последним обновлением |
| `lang-switcher restore ПУТЬ_К_КОПИИ` | Восстановить конкретную резервную копию |
| `lang-switcher uninstall` | Удалить установленную версию и восстановить состояние до первой установки |

Для обновления нужен опубликованный GitHub-репозиторий. Если он не был задан
при установке из локального архива, укажите его при первом обновлении:

```bash
lang-switcher update --repository OWNER/lang-switcher
```

`rollback` и `restore` возвращают сохранённый снимок настроек.
`uninstall` сохраняет посторонние настройки, добавленные после установки.
Если до первой установки уже был старый скрипт, удаление вернёт его.
Общие пакеты APT и резервные копии при удалении остаются.

## Файлы и резервные копии

Для обновления прежних установок часть внутренних путей сохранена:

```text
~/.local/bin/lang-switcher
~/.local/bin/switch_layout.sh
~/.local/bin/switch_case.sh
~/.local/bin/zorin-switcher/
~/.local/share/gnome-shell/extensions/lang-switcher@local/
~/.local/share/zorin-switcher/
```

Резервные копии находятся в:

```text
~/.local/share/zorin-switcher/backups/
```

При ошибке во время замены файлов или настройки GNOME установщик пытается
автоматически вернуть предыдущие файлы и настройки. Установленные системные
пакеты APT при этом не удаляются.

После успешной ручной установки скачанный архив, файл SHA256 и распакованная
папка комплекта больше не нужны. Удаляйте именно загрузку, сохраняя перечисленные
выше установочные каталоги. Однокомандная установка очищает свою временную
папку автоматически.

## Проверки и сборка для GitHub

```bash
make test
make bundle REPOSITORY=OWNER/lang-switcher
```

Сборка создаёт:

```text
dist/lang-switcher.tar.gz
dist/lang-switcher.tar.gz.sha256
```

Python wheels скачиваются в игнорируемую папку `wheels/`, в Git не попадают.
При уже подготовленном кеше можно собрать без сети:

```bash
python3 scripts/build_release.py --repo OWNER/lang-switcher --no-download
```

`make test` не устанавливает программу и не меняет настройки рабочего стола:
проверки используют временные HOME и подставной backend GSettings. Проверяются
обновление старой установки, чужие сочетания, повторная установка, откат,
удаление и очистка временной папки bootstrap, включая ошибки загрузки.

На целевом Zorin можно проверить Python-зависимости в одноразовом окружении,
без установки переключателя и без отправки нажатий:

```bash
python3 scripts/smoke_runtime.py
```

В `.github/workflows/` подготовлены тесты и публикация Release по тегу `v*`.
Перед публикацией выставьте `VERSION`, затем отправьте соответствующий Git-тег.
Workflow проверяет совпадение тега с VERSION, собирает комплект и прикладывает
его к GitHub Release. Источник команд Actions — официальные проекты
[checkout](https://github.com/actions/checkout),
[setup-python](https://github.com/actions/setup-python) и
[GitHub CLI](https://cli.github.com/manual/gh_release_create).

Исходный пользовательский переключатель был основан на модификации скрипта
Михаила Винакова. Эта версия сохраняет его поведение преобразования и добавляет
интеграцию GNOME, обработку ошибок и установку/обновление.
