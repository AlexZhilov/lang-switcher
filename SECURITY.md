# Безопасность и приватность

Проверка перед публичной публикацией: 12 ноября 2026 года.
Проверены исходники, подготовленный Git-индекс, релизный архив и содержимое
поставляемых Python wheels. Это проверка конкретной версии, а не гарантия
отсутствия всех возможных, в том числе неизвестных, уязвимостей.

## Что исключено из публикации

- Пользовательские настройки GNOME, резервные копии, домашние каталоги,
  ключи SSH/API, пароли, токены, история терминала и буфер обмена не включаются.
- Прежний персональный UUID расширения заменён на `lang-switcher@local`.
  Старые установки обнаруживаются локально по интерфейсу расширения,
  без встраивания имени владельца в исходники.
- Архив собирается по фиксированному списку файлов. В него не попадают `.git`,
  `.env`, локальные отчёты `.build/`, тестовые окружения или резервные копии.
- В tar нормализованы UID/GID, имена владельца/группы и времена файлов.
- Локальные Git-коммиты не создавались. Для этого подготовленного репозитория
  настроен нейтральный автор `lang-switcher contributors` с адресом
  `contributors@lang-switcher.invalid`; глобальные настройки Git не менялись.
  В собственной копии выбирайте публичную идентичность или GitHub noreply:
  автор и email каждого созданного Git-коммита становятся частью истории.
- Email авторов сторонних библиотек в их лицензиях/метаданных — публичные
  данные этих проектов. Лицензии и указание исходного автора сохраняются.

## Как работает программа

Обрабатывается выделенный пользователем текст по явной команде. Программа
не записывает нажатия клавиш и не отправляет выделенный текст по HTTP.
Связь с GNOME идёт по локальному пользовательскому D-Bus, ввод — через X11.
Отдельного фонового Python-сервиса и сетевой телеметрии нет.

Резервные копии установки содержат прежние пользовательские файлы и настройки,
поэтому их каталоги имеют права `0700`, а state.json — `0600`. Они остаются на
целевом ПК и не входят в релизы. Восстанавливайте только собственные копии:
восстановление возвращает исполняемый код и команды горячих клавиш.

Журналы установки также остаются локальными: каталог имеет права `0700`,
файлы — `0600`. В них сохраняется диагностический вывод APT/pip и команд
настройки, включая локальные пути. Журналы не включаются в релизы.
Пароль sudo запрашивается непосредственно в терминале и в журнал не пишется.

## Ограничение изменений и удалений

Установщик работает от обычного пользователя. Sudo используется только для
фиксированного списка пакетов APT; скачанный Python-код не запускается от root.
Прямые изменения файлов/восстановление ограничены известными путями программы
в HOME. Переход через родительскую символическую ссылку за пределы HOME
отклоняется. GSettings ограничены источниками ввода, своим расширением и
пользовательскими сочетаниями клавиш.

Временная загрузка имеет отдельный каталог mktemp и удаляется после bootstrap.
Распаковка запрещает выход за пределы каталога, символические/жёсткие ссылки
и специальные файлы. Проверяется SHA256 архива и manifest каждого файла.
Для доверия к обновлениям требуется доверять выбранному GitHub-репозиторию:
контрольная сумма из того же Release подтверждает целостность загрузки.

Удаление сохраняет посторонние настройки, добавленные после установки,
не удаляет общие пакеты APT и оставляет резервные копии. Удаляются только
отдельные окружения, созданные этой программой и помеченные её маркером.
Явный rollback/restore возвращает сохранённый снимок настроек.

Дополнение Bash устанавливается отдельным пользовательским файлом. `.bashrc`
не изменяется. При нажатии Tab выполняется только локальное чтение имён файлов
и работа со встроенными средствами Bash, без запуска CLI или сетевых запросов.
Файлы, добавленные последующими обновлениями, сохраняют отдельную ссылку на
свой исходный снимок для корректного удаления и восстановления.

## Зависимости и CI

Ненужная цепочка PyAutoGUI/PyScreeze/Pillow удалена. Для клавиатуры используются
небольшой собственный адаптер X11, `python-xlib`, `six` и `pyperclip`.
Установочный комплект содержит только эти три Python-зависимости.
Проверка публичных version advisories PyPI не обнаружила известных
уязвимостей у выбранных версий. Повторить проверку:

```bash
python3 scripts/audit_dependencies.py
```

Скрипт передаёт PyPI только общедоступные названия пакетов и версии. Проверка
включена в CI и сборку релиза. Её результат меняется по мере публикации новых
сведений. Она не является полным аудитом кода библиотек или пакетов ОС.

GitHub Actions закреплены за commit SHA. Сохранение credentials checkout
отключено; workflow с pull request имеет только read-доступ к contents.
`GH_TOKEN: ${{ github.token }}` — ссылка на выдаваемый GitHub во время job токен,
его реального значения в исходниках и архиве нет. Токен используется только
для публикации релиза при отправке тега.
