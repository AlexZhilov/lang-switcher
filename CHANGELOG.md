# История изменений

## 1.0.1

- Короткий вывод установщика и управляющих команд с этапами и цветными статусами.
- Подробности pip/APT сохраняются в закрытый локальный журнал; флаг `--verbose` показывает их в консоли.
- Подсказки по активации и откату сокращены; путь к копии и журналу доступен через `status --verbose`.
- Загрузка релиза больше не выводит таблицы прогресса curl.

## 1.0.0

- Преобразование выделенного текста RU/EN вместе с выбором языка ввода.
- Прямая смена языка через GNOME 43 без имитации Alt+Shift.
- Переключение регистра, обработка ведущих отступов и восстановление текстового буфера.
- Установка поверх старого скрипта или с нуля, отдельное Python-окружение.
- Обновление, резервные копии, откат и удаление с восстановлением прежних настроек.
- GitHub Release с Python-зависимостями и автоматической очисткой временной загрузки.
