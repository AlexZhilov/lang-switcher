lang-switcher — установка для Zorin OS / GNOME 43 / X11

Запускать от обычного пользователя в терминале рабочего стола, БЕЗ sudo:
  ./install.sh --check-only
  ./install.sh

Установщик обновляет прежний zorin-switcher или устанавливает его с нуля.
Ctrl+Shift+Пробел — раскладка выделенного текста и язык ввода.
Ctrl+Shift+Q — регистр выделенного текста.

После первой установки загрузите модуль GNOME:
переключитесь на английский язык, Alt+F2, введите r, Enter.
Либо выйдите из учётной записи и войдите снова.

Команды после установки:
  lang-switcher status
  lang-switcher update
  lang-switcher rollback
  lang-switcher uninstall
  lang-switcher restore /путь/к/резервной-копии

Python-зависимости находятся в wheels/ и устанавливаются в отдельное окружение.
В поставку включены три зависимости на чистом Python без Pillow/PyAutoGUI.
Системный X11 должен быть доступен в пользовательской графической сессии.
При необходимости недостающие системные пакеты устанавливаются через sudo APT.
Интернет не нужен, если системные пакеты уже стоят и wheels совместимы:
  ./install.sh --offline

Файлы и настройки предыдущей версии сохраняются в
  ~/.local/share/zorin-switcher/backups/
При ошибке во время замены файлов/настроек выполняется автоматический откат.
Общие пакеты APT не удаляются при откате и удалении.
Установка системных пакетов и подготовка Python-окружения не откатываются.

Удаление восстанавливает состояние до первой установки: если раньше уже был
старый скрипт, он вернётся. Свои резервные копии установщик оставляет.
Bootstrap-команда удаляет только временную папку со скачанным архивом.
Установленная программа, нужные библиотеки и резервные копии сохраняются.
Папку с распакованным комплектом можно удалить после успешной установки.

Внутренние пути zorin-switcher сохранены для совместимости:
  ~/.local/bin/zorin-switcher/zorin_switcher.py
  ~/.local/bin/switch_layout.sh и switch_case.sh
  ~/.local/share/gnome-shell/extensions/lang-switcher@local/
  ~/.local/share/zorin-switcher/ — окружения, управляющий скрипт, бэкапы

Требуется включённая поддержка пользовательских расширений GNOME.
Несовместимая версия GNOME/Wayland и чужая занятая горячая клавиша приводят
к отказу от установки до замены скрипта. Другие сочетания клавиш сохраняются.
Модуль использует внутренние API GNOME 43; другие основные версии не заявлены.
Буфер обмена сохраняется как текст; изображения/другие форматы не сохраняются.
Полный исходный код, история версий и описание: README.md в GitHub-проекте.
