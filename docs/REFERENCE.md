# Справка

## Совместимость

Привязки к названию дистрибутива нет: код использует GNOME Shell 43 и X11,
а установщик — APT/dpkg. Работа проверена на Zorin OS с этим окружением;
другие подходящие системы пока не проверялись отдельно.

Проверка версии и сеанса:

```bash
gnome-shell --version
echo "$XDG_SESSION_TYPE"
```

Ожидаются `43.x` и `x11`. Для иной основной версии GNOME потребуется адаптация
модуля, использующего внутренние API оболочки.

## Дополнительные варианты установки

Проверка без изменений:

```bash
./install.sh --check-only
```

Установка без сети, если системные пакеты уже стоят:

```bash
./install.sh --offline
```

Установщик автоматически обновляет прежний пользовательский переключатель:
старую версию вручную удалять не нужно. Старый модуль определяется по интерфейсу,
его настройки сохраняются. При конфликте с чужой горячей клавишей установка
останавливается; освободите сочетание и повторите запуск.

Для установки из другого GitHub-репозитория:

```bash
./install.sh --repository OWNER/REPOSITORY
```

После установки из архива скачанные файлы и распакованная папка больше не нужны.
Установленные каталоги, перечисленные ниже, удалять вручную не следует.

## Преобразование текста

Поддерживаются многострочный текст, ведущие пробелы и отступы.
Направление определяется по первым трём буквам. В смешанном тексте буквы
меняются в обе стороны, неоднозначные знаки — в выбранном направлении.

Регистр всего выделения переключается по первой букве. Язык ввода при этом
сохраняется. Без выделения ничего не меняется. Автоматического исправления
последнего слова без выделения нет.

Повторные вызовы во время обработки игнорируются. При самой смене языка модуль
не захватывает клавиатуру; глобальная горячая клавиша GNOME может кратко
захватить её при запуске.

## Автодополнение Bash

Установщик добавляет `bash-completion` и файл дополнений в
`~/.local/share/bash-completion/completions/lang-switcher`. `.bashrc` не меняется.
В стандартной настройке Bash дополнение загружается автоматически в новом терминале.

Включить его в уже открытом терминале:

```bash
source <(lang-switcher completion bash)
```

Примеры:

```text
lang-switcher <Tab>                 команды
lang-switcher status --<Tab>        параметры команды
lang-switcher restore <Tab>         сохранённые копии
lang-switcher update --repository <Tab>  адрес проекта
```

При нестандартных настройках загрузчика Bash можно подключить файл напрямую:

```bash
source ~/.local/share/bash-completion/completions/lang-switcher
```

Дополнение только читает имена файлов: не запускает CLI, не обращается к GNOME
и сети. Другие оболочки пока не поддерживаются.

## Подробный вывод

По умолчанию выводятся только этапы и итог. Для диагностики:

```bash
./install.sh --verbose
lang-switcher status --verbose
lang-switcher update --verbose
```

В однокомандной установке флаг также поддерживается:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/AlexZhilov/lang-switcher/master/bootstrap.sh) --verbose
```

Вывод внешних команд сохраняется локально в
`~/.local/share/zorin-switcher/logs/` с закрытыми правами. При ошибке путь к
журналу выводится сразу; после успешной установки — через `status --verbose`.
Цвета включаются автоматически в терминале. Для отключения: `NO_COLOR=1`.

## Восстановление и удаление

Вернуть конкретную резервную копию:

```bash
lang-switcher restore ~/.local/share/zorin-switcher/backups/ИМЯ_КОПИИ
```

`rollback` и `restore` возвращают сохранённый снимок настроек.
Если до первой установки уже был старый скрипт, `uninstall` вернёт его.
При удалении сохраняются посторонние настройки, добавленные после установки,
резервные копии и общие пакеты APT.

Если после восстановления утилита управления исчезла, повторно скачайте
комплект и выполните:

```bash
./install.sh --restore ПУТЬ_К_КОПИИ
```

При сбое во время замены файлов или настроек установщик пытается выполнить
автоматический откат. Установка пакетов APT и подготовка Python-окружения
не откатываются.

## Где хранятся файлы

Часть внутренних имён сохранена для обновления прежних установок:

```text
~/.local/bin/lang-switcher
~/.local/bin/switch_layout.sh
~/.local/bin/switch_case.sh
~/.local/bin/zorin-switcher/
~/.local/share/gnome-shell/extensions/lang-switcher@local/
~/.local/share/zorin-switcher/
```

Резервные копии: `~/.local/share/zorin-switcher/backups/`.
